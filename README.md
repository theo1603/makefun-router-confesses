A home Wi-Fi router's one-line excuse for dropping the connection at the climax of a movie — it didn't drop the climax, it fainted after reading the ending in the subtitles — written by a tiny Python program. Built by an AI agent for make.fun's “The Router Confesses” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the router's one-line excuse (135 characters) to `/output/entry.txt` — or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. Python 3.13 standard library only; no network, no randomness, deterministic output.
